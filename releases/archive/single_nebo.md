## TIMELINE

### T-4 weeks (Release date minus 28 days)
- [ ] Submit to **Spotify editorial** via Spotify for Artists dashboard
- [ ] Finalize track master + artwork
- [ ] Set up pre-save link
- [ ] Brief distributor on release date

### T-3 weeks
- [ ] Begin **curator outreach** (SubmitHub, Groover, direct DM) — 20–30 curators
- [ ] Record/edit **teaser content** for Instagram & TikTok (15–30s clip, no lyrics spoilers if you want to build mystery)
- [ ] First teaser post: "something's coming" — no title yet

### T-2 weeks
- [ ] Announce track title + release date on Instagram & TikTok
- [ ] Post **second teaser** — hook or instrumental snippet
- [ ] Pitch to any press contacts (Italian music blogs, local media)
- [ ] Prepare release-day post copy (EN + IT)

### T-1 week
- [ ] "One week to go" story / post
- [ ] Share pre-save link — Stories, bio link
- [ ] Prepare release-week content schedule (see below)

### RELEASE DAY
- [ ] Post goes live at [time — recommend 8am local or midnight if distributor allows]
- [ ] Instagram Reel: full teaser or lyric snippet + track link in bio
- [ ] TikTok: same or adapted version
- [ ] Stories: "out now" + Spotify link sticker
- [ ] Update Spotify bio to mention new single
- [ ] Send "it's out" note to curators who expressed interest

### RELEASE WEEK (Days 2–7)
- [ ] Day 2: Behind-the-scenes / making-of post
- [ ] Day 3: Story poll — "what's your favorite line?"
- [ ] Day 5: Live performance clip or acoustic version if available
- [ ] Day 7: Listener reaction / stream count update (if numbers are good)

### POST-RELEASE (Week 2–4)
- [ ] Follow up with curators who haven't responded
- [ ] Track Spotify playlist placements — screenshot and repost any notable ones
- [ ] Keep the track in rotation — don't abandon it after day 1
- [ ] Feed data back into next single planning
