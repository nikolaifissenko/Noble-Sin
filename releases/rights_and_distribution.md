# Rights Split & Distribution — Decisions Log

> Band-wide policy, first applied to "Nebo" (25/08/2026). Applies to future self-written tracks unless a specific song's contribution breakdown changes the split.

---

## 1. RIGHTS SPLIT — SIAE

**Decision:** 5-way equal split, 20% each, for all self-written tracks. Independent — no external editore (publisher). The band keeps 100% (author share + what would be the publisher's share, since none is assigned).

**Qualifica per member (for "Nebo"):**

| Role | Qualifica (SIAE) | Quota |
|---|---|---|
| 4 musicians | Autore della musica | 20% each |
| Vocalist | Autore del testo | 20% |

**Deposit steps (per track):**
1. Each member must be individually associated/enrolled with SIAE (not the band as an entity) — check who still needs to register (siae.it or SIAE+ app, ~€95/yr, free under 30)
2. Deposit the work as inedito via Portale Autori ed Editori / SIAE+ app before release
3. Fields: Titolo, Autori (name + qualifica per above table), Quote di ripartizione (20% each), Editore = none
4. All 5 co-authors must confirm/sign the declared quotas

## 2. DISTRIBUTION

**Decision:** DistroKid, **Musician Plus plan (~$39.99/yr)** — not the base plan, because Spotify editorial pitching access requires it.

**Why DistroKid over TuneCore/CD Baby:**
- 100% royalties kept (same as TuneCore; CD Baby takes a permanent 9% cut)
- Built-in **Splits** feature — pay each of the 5 members automatically from streaming/download revenue using the same 20% each, no manual division needed
- Musician Plus unlocks Spotify for Artists pitching access + custom release dates

**Action when uploading each single:**
1. Upload mastered WAV + artwork + metadata
2. Set up **Splits**: 20% each of the 5 members (same logic as SIAE, but this is a separate system — streaming/download revenue, not performance-royalty collection)
3. Enable Spotify pre-save
4. Once live in Spotify for Artists, pitch to editorial (ideally 4 weeks before release per band's own strategy)
