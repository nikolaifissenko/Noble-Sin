# Instagram ads log (Nikolai's own money, his call)

## Test 1: Nebo reel, chorus + bridge with war footage
- Boosted: 03/11/2026 by Nikolai (from Ads Manager / browser, no Apple fee)
- Budget: 5 EUR/day x 7 days = 35 EUR
- Goal: profile visits. Audience "Nebo rock IT": Italy, 18 to 40, music interests only.
- Check: Sun 08/11 (stop only if cost per follower > 1 EUR). Decide: Wed 11/11.
- Risk: Meta may flag it as social issue / sensitive (war footage); in the EU Meta no longer runs social issue ads.
- Check 08/11 (day 5): spent 25.98/35 EUR. Views 10,699, reach 9,682, 3s plays 4,428 (41%). Likes 31, saves 5, shares 3. Profile visits 903 (0.03 EUR each) but FOLLOWERS 1 = ~26 EUR/follower. Audience 88.6% men.
- Placements were Advantage+ (Instagram AND Facebook), not Instagram only: many "profile visits" likely went to the Facebook Page or were junk taps.
- Verdict: rule triggered (>1 EUR/follower). Stop. Lesson: profile visits objective + Advantage+ placements = cheap clicks, no follows. Next test only via Ads Manager, Instagram only (Feed, Reels, Explore), manual placements.
